# LifeBoard · 每日任务日历 & 夯 → 拉 榜

一个纯前端、零依赖、数据只存在自己设备上的小网站。电脑和 iPhone 都能用。

- **日历任务**：月视图看每天的任务，点某一天就能加任务、打勾、写备注、标优先级；逾期未完成会单独提醒。
- **常用任务**：经常重复的事（买菜、交房租、周报）存成"常用"，点一下就能加到当天，还能记住优先级和使用次数。
- **夯 → 拉 榜**：上传图片，拖进「夯 / 顶级 / 人上人 / NPC / 拉」不同档位，给每张图打 1–5 星、写评语，还可以切到「评分表」按星级排序看。
- **榜单分类**：可以建多个互不干扰的榜单，比如「国内山的综合评价」「泡面排行」，每个榜单有自己的一套档位和图片。
- **删除都会问一遍**：删任务、删图片、删档位、删榜单、清空数据，全部弹出确认框写清楚要删什么，点错了可以取消。
- 图片上传前会自动压缩（最长边 1600px），省空间。
- 没有服务器、没有账号：所有数据存在浏览器的本地数据库（IndexedDB）里。

## 一、怎么用

### 方式 A：GitHub Pages（推荐，手机和电脑都能用，出门也能开）

**已经部署好了，直接打开：**

```
https://clever6299.github.io/lifeboard/
```

电脑和 iPhone 都用这个网址，数据各自存在本机，需要时用「导出 / 导入」互传（见第二节）。

iPhone 上用 Safari 打开后，点底部「分享」→「添加到主屏幕」，就变成一个全屏 App 图标，断网也能打开。

### 方式 B：在电脑上本地跑

双击项目里的 **`start.cmd`**（需要装了 Node.js），浏览器会自动打开 `http://localhost:5173`。
命令行窗口里还会打印一个局域网地址，例如 `http://192.168.1.20:5173`，**iPhone 连同一个 WiFi 就能直接访问**。

也可以在命令行里手动跑：

```bash
node server.js          # 默认 5173 端口，被占用会自动往后找
PORT=8080 node server.js
```

> 注意：不要直接双击 `index.html` 打开。`file://` 模式下浏览器禁止网页保存数据，页面顶部会给出提示。

### 方式 C：随便找个静态托管

整个项目就是一堆静态文件，扔到 Netlify / Vercel / Cloudflare Pages / 自己的服务器上都能跑，不需要构建。

## 二、电脑 ↔ iPhone 怎么同步数据

数据默认各存各的，同步靠**导出 / 导入一个 JSON 文件**：

1. 在电脑上打开页面 → 右上角 **⚙ 设置** → **导出备份 (.json)**，浏览器会下载
   `lifeboard-backup-20250601-2130.json`。任务、常用任务、榜单、档位、图片、星级、评语**全都在这个文件里**。
2. 把这个文件传到手机：微信文件传输助手 / AirDrop / iCloud 都行。
3. 手机上打开同一个网址 → **⚙ 设置** → **导入备份…** → 选中那个 json → 选
   - **合并**：保留手机现有的数据，同 ID 的条目被覆盖（推荐，日常用这个）
   - **覆盖**：先清空手机上的全部数据，再导入（换设备、想完全一致时用）
4. 反向操作同理（手机上导出 → 电脑上导入）。

图片是以 base64 内嵌在 json 里的，所以**备份文件可能几十 MB**，属于正常现象。
如果只想同步任务不想传图片，可以把设置里的「导出时包含图片」取消勾选。

> 想彻底不用手动传文件，就得搭后端（比如 Supabase）做云同步，那需要注册账号和密钥。当前版本刻意做成"零账号"。

## 三、使用小技巧

| 操作 | 说明 |
| --- | --- |
| 日历格子 | 点日期看当天任务；点别的月份的灰格子会跳到那个月 |
| 任务标题 | 点一下就能就地编辑标题、备注、日期、优先级 |
| `只看未完成` | 汇总所有还没做的任务，逾期会标出来 |
| 存为常用任务 | 两个入口：在输入框写好内容后点「＋ 存为常用」；或点任务右边的 `☆` 把整条任务（含备注和优先级）存下来 |
| 用常用任务 | 点「★ 常用任务」展开，点任意一条就加到当前选中的日期。用得越多排得越前，右边 `×` 可以删掉 |
| 新建榜单 | 棒拉榜顶部「＋ 新建榜单」，比如「国内山的综合评价」「泡面排行」。新榜单会自动带上默认五档，和别的榜单完全隔离 |
| 切换榜单 | 点顶部的榜单标签；标签上的数字是这个榜单里的图片数 |
| 改名 / 删除榜单 | 顶部「改名」「删除榜单」。删除会连带删掉该榜单的档位、图片卡片和图片文件，别的榜单不受影响；只剩一个榜单时不允许删 |
| 改档位名字 / 颜色 | 点档位名字可以直接改；点档位里的 `改` 按钮可以同时改名字并从调色板里挑颜色 |
| `未分档` | 固定在**页面最下面**，新上传的图片先落在这里，再拖到档位里 |
| 图片卡片（电脑） | 直接拖动到别的档位；拖到某张卡片前面可以插队 |
| 图片卡片（手机） | 点一下打开详情，在那里换档位、打星、写评语 |
| 批量加图 | 电脑上可以一次选多张，或直接把图片拖进页面，或 `Ctrl`/`⌘`+`V` 粘贴 |
| 删档位 | 点档位里的 `删`。里面的图片会回到「未分档」，图片本身不会丢 |
| 误删档位 | 设置里点「恢复默认五档」，缺哪个补哪个，而且会补回它原本的位置（夯永远在最上面），已有的档位不动 |
| `Esc` | 关闭弹窗 |

## 四、项目结构

```
lifeboard/
├── index.html                 页面骨架（两个视图 + 三个弹窗）
├── styles.css                 全部样式（台历风格，自动亮/暗色）
├── DESIGN.md                  设计说明：为什么长这样，改之前先看
├── manifest.webmanifest       PWA 清单，用于"添加到主屏幕"
├── sw.js                      Service Worker，离线缓存
├── server.js                  零依赖本地静态服务器
├── start.cmd                  Windows 双击启动
├── js/
│   ├── ui.js                  通用工具（确认框、输入框、转义、日期、toast）
│   ├── store.js               IndexedDB 封装 + 图片压缩 + 导入导出
│   ├── calendar.js            日历任务页
│   ├── tier.js                夯拉榜页
│   └── app.js                 外壳：视图切换、设置、备份、离线注册
├── icons/                     应用图标
└── tools/make-icons.py        重新生成图标（可选，需要 Pillow）
```

技术栈就是原生 HTML + CSS + JavaScript，没有构建步骤、没有 `node_modules`、不请求任何 CDN。
改完文件刷新页面即可生效。

界面是照着「台历 + 排名条」这个方向做的：日历是真正的印刷网格，今天是一整格实心红块，
榜单是一条压一条的实色色带。**自动跟随系统的亮色 / 暗色模式**。
设计令牌和取舍理由都写在 [DESIGN.md](DESIGN.md) 里，改样式之前建议先看一眼。

数据模型（都放在 IndexedDB 的 `lifeboard` 库里）：

| 对象仓库 | 装什么 |
| --- | --- |
| `boards` | 榜单分类（国内山的综合评价 / 泡面排行 …） |
| `tiers` | 每个榜单自己的档位（夯 / 顶级 / …），带 `boardId` |
| `items` | 图片卡片：属于哪个榜单、哪个档位、几星、评语 |
| `images` | 压缩后的图片本体 |
| `tasks` | 每天的任务 |
| `templates` | 常用任务 |

## 五、数据存在哪 / 怎么彻底删掉

- 存在浏览器的 IndexedDB（数据库名 `lifeboard`），按**网址**隔离。
  `localhost:5173` 和 `xxx.github.io` 是两个互不相通的存储空间，导入导出就是在它们之间搬数据。
- 设置里点「清空全部数据」会删掉本机全部内容。
- 浏览器清缓存时如果勾选了"网站数据"，数据也会一起没，**重要内容记得偶尔导出备份**。

## 六、部署到 GitHub Pages

仓库已经在 <https://github.com/clever6299/lifeboard>，Pages 已开启，以后改完代码这样更新：

```bash
git add .
git commit -m "描述这次改了什么"
git push
```

推送后 GitHub 会在一两分钟内自动重新发布，刷新网址即可看到新版。
（如果手机上看不到新版，见第七节的 Service Worker 缓存那一条。）

如果要在别的账号 / 别的仓库重新部署一次：

```bash
git init
git add .
git commit -m "feat: LifeBoard 每日任务日历 + 夯拉榜"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

然后在 GitHub 仓库页面：**Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录选 `/ (root)` → Save**。

## 七、更新与常见问题

- **改了代码手机上看不到新版？** Service Worker 会缓存外壳文件。把 `sw.js` 里的
  `const CACHE = 'lifeboard-v2'` 改成 `v3`、`v4`…… 再刷新即可让所有设备拿到新版。
  （如果这一步忘了做，已经打开过网站的设备会一直用旧版，**这是最容易踩的坑**。）
- **误删了「夯」怎么办？** 设置 → 档位 → 「恢复默认五档」，缺的会补回来并放回原位。
- **误删了任务或图片？** 页面上的删除都有确认框。如果已经确认删掉了，只能从之前的备份 json 里恢复，
  所以重要内容记得偶尔导出一次。
- **iPhone 上传图片没反应？** 确认是从 Safari 打开的页面，并且给过一次"选择照片"的授权。
- **能存多少张图？** 浏览器一般允许每个站点用几百 MB 到几 GB（设置里有显示用量）。每张压缩后的图通常 100–400 KB。
- **换手机/换电脑怎么办？** 导出 json，在新设备上导入即可。旧版本导出的备份（没有榜单概念）也能正常导入，
  会自动归到「我的榜单」里。
- **`file://` 打不开数据？** 正常现象，用 `start.cmd` 或 Pages 网址。
